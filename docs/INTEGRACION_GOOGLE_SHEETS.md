# Integración Google Sheets

Para el piloto no se configurará conexión a Nave. La integración Parte Diario será opcional y privada: administración registra ID de hoja y pestaña; una cuenta de servicio u OAuth de servidor obtiene lectura sin publicar la hoja.

La sincronización presenta cambios antes de aplicarlos, guarda ejecución y error, y nunca elimina historiales. Los cambios de nómina desactivan/marcan revisión; no borran vendedores. La programación se ejecuta del lado servidor. El proxy de URL actual se elimina por permitir destinos arbitrarios.
